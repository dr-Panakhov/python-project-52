## Стек

- Python 3.10+
- Django
- uv
- PostgreSQL

## Установка

Клонирование репозитория:
`git clone https://github.com/dr-Panakhov/python-project-52.git`
`cd python-project-52`

Установка зависимостей и подготовка базы данных:
`make install`
`make setup`

## Использование

Запуск локального сервера:
`make start`
